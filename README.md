# 半信半疑文庫 ― Library

縫い目を見せる論考と、それを支える道具置き場。
断言の代わりに「判断の宙づり」を並べておくための、私設の小さな書架。

## 開き方

`index.html` をブラウザで開く（ローカルでもダブルクリックで動く）。
GitHub Pages にデプロイする場合はリポジトリ Settings → Pages → main / root。

## 中の歩き方

```
本館（ロビー）
 ├─ 東翼：文庫 ──── 認識のクセを巡る書架（論考）
 │   ├─ 棚01 ラベルで人を括る
 │   ├─ 棚02 「正しさ」のすれ違い
 │   ├─ 棚03 わかりやすさの罠
 │   └─ 棚04 趣味の評価軸
 └─ 西翼：ツール棚 ── 制作と観察を補う実用書
```

棚は **題材ジャンルではなく「認識のクセ」で分けている**。
ゲームの話もネット文化の話も、扱っている認識の機構が同じなら同じ棚に並ぶ。
これは半信半疑文庫の最も中核の設計判断。

## 論考の共通形式

文庫の本はすべて、同じ五節構造に沿って書かれる:

| 節 | 役割 |
|----|------|
| §0 | 扱う現象を、価値判断を抜いて記述 |
| §1 | フレーム A で論じる → 結論 A |
| §2 | フレーム B で論じ直す → 結論 B |
| §3 | フレーム対比 ― なぜ同じ現象から違う結論が出るのか |
| §4 | 自己バイアスの開示 ― この論考自身の偏りを開示する |

§4 があるのが半信半疑文庫の刻印。「X とはこういうものだ」と断言せず、
「ラベルの付け方が結論を生んでいる」を読者に持ち帰らせることを狙う。

## ファイル構成

```
Library/
├── index.html               # ロビー
├── README.md
├── assets/
│   └── lobby.css            # ロビー＆棚ページ共通スタイル（論考本体は触らない）
├── essays/
│   ├── index.html           # 文庫トップ（4 棚一覧）
│   ├── shelves/
│   │   ├── 01_labeling.html
│   │   ├── 02_rightness.html
│   │   ├── 03_clarity_trap.html
│   │   └── 04_taste_axes.html
│   └── books/
│       ├── shijichu_psychology.html
│       └── shinpan_no_inai_shiai.html
└── tools/
    └── index.html
```

論考の本体（`books/*.html`）は、それぞれが自前の CSS を内部に持つ。
共通スタイルは適用しない。各論考の「声」を保つための意図的な選択。
